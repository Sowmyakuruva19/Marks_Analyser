# Student Marks Analyzer

A NumPy-based tool that analyzes student marks across multiple subjects — built without pandas, using only NumPy array operations.

## Features

- Generates a random dataset of 10 students' marks across 5 subjects
- Calculates total and average marks per student
- Calculates total and average marks per subject
- Identifies the topper and lowest scorer
- Assigns letter grades (A/B/C/D/F) based on average marks
- Calculates subject-wise pass percentage (pass mark: 40)
- Ranks all students by total marks, highest to lowest

## Tech Used

- Python
- NumPy

## How to Run

```bash
python marks_analyser.py
```
